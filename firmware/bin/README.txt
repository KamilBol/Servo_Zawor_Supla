===================================  INSTRUKCJA FLASHOWANIA (.BIN)  ======================================
Uruchom ESP8266 Download Tool -> Developer Mode -> ESP8266.

SEKCJA "SPIDownload": [X] Zaznacz "ptaszka" przy ścieżce pliku. [...] Wybierz plik: STEROWNIK_ZAWORU.ino.bin [@] Adres wpisz: 0x00000

PARAMETRY (Wemos D1 Mini):

Crystal Freq: 26M

SPI SPEED: 40MHz

SPI MODE: DIO <-- WAŻNE!

FLASH SIZE: 32Mbit

PODŁĄCZENIE:

COM: Wybierz swój port.

BAUD: 921600 (lub 460800).

AKCJA: Kliknij START. Jak zobaczysz "FINISH", odłącz i podłącz zasilanie. Gotowe.
